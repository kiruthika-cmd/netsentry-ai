f# NetSentry AI
### AI-Assisted Passive Network Threat Detection and Intelligence Platform

## About the Project

NetSentry AI is a cybersecurity project designed to passively monitor network traffic, identify unusual activities, and detect potential network threats using AI-based analysis.

The platform aims to help users understand suspicious network behaviour through traffic analysis, risk scoring, and security alerts.

## Objectives

- Monitor network traffic without modifying it.
- Identify suspicious network activities.
- Detect unusual traffic patterns using AI.
- Generate security alerts and risk scores.
- Support network security investigation.

## Key Features

1. **Passive Network Monitoring** – Observe network traffic without interrupting communication.
2. **AI-Based Anomaly Detection** – Identify unusual network behaviour.
3. **PCAP File Analysis** – Analyse captured network traffic files.
4. **Attack Traffic Simulation** – Test detection capabilities using simulated traffic in an authorised environment.
5. **Threat Intelligence Integration** – Use threat intelligence information to support investigations.
6. **Explainable AI Risk Scoring** – Provide understandable reasons behind threat risk scores.
7. **Incident Investigation and Report Generation** – Support security analysis and reporting.
